# CivicFix

> **Report. Track. Improve your community.**

CivicFix is a civic-tech web platform that helps citizens report and track local problems such as potholes, garbage, broken streetlights, water leakage, and damaged public infrastructure.

## 🚀 Features

### Citizens
- Register & Login
- Report civic problems
- Add category, location, description and photo
- Get a unique Report ID
- Track report status
- Personal dashboard
- Profile & theme settings

### Admin
- Admin dashboard
- View all reports
- Search & filter reports
- Update report status
- Monitor issue statistics

### Report Lifecycle

**Pending → In Progress → Resolved**

## 🛠️ Tech Stack

- React + Vite
- Node.js + Express
- PostgreSQL + Neon
- JWT Authentication
- bcrypt
- Vercel
- GitHub

## 🔄 How It Works

**Citizen → Report Issue → Get Report ID → Track Status → Admin Updates → Resolved**
